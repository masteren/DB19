# DB設計書 — テーブル設計

```
コース表               コース担当表         講師表
─────────────          ─────────────        ─────────────
コースコード PK  ←FK─  コース・コード PK    講師ID     PK

```

## テーブル定義書

### T_Course（コース表）

| NO. | 日本語項目名 | システム項目名  | データ型    | 長さ | キー | 制約     | 備考                   |
|-----|------------|----------------|-------------|------|------|----------|------------------------|
| 1   | コースコード | F_CourseCode   | CHAR        | 4    | PK   | NOT NULL | 英字2字＋数字2桁（例：JV01）|
| 2   | コース名称   | F_CourseName   | VARCHAR     | 100  |      | NOT NULL |                        |
| 3   | 料金        | F_CourseFee    | INT         |      |      | NOT NULL | 未定の場合は 0 を入力   |
| 4   | 開催期間    | F_EventPeriod  | INT         |      |      | NOT NULL | 単位：日               |

**サンプルデータ**

| F_CourseCode | F_CourseName   | F_CourseFee | F_EventPeriod |
|--------------|----------------|-------------|---------------|
| JV01         | JAVA入門       | 10000       | 1             |
| JV03         | JAVA応用       | 30000       | 3             |
| UX01         | UNIX入門       | 10000       | 1             |
| UX13         | UNIX構築       | 30000       | 3             |
| NT01         | NetWork入門    | 10000       | 1             |
| NT15         | NetWork構築    | 35000       | 5             |

### T_Assignments（コース担当表）

| NO. | 日本語項目名 | システム項目名    | データ型 | 長さ | キー | 制約     | 備考                          |
|-----|------------|------------------|----------|------|------|----------|-------------------------------|

### T_Instructors（講師表）

| NO. | 日本語項目名 | システム項目名    | データ型    | 長さ | キー | 制約     | 備考             |
|-----|------------|------------------|-------------|------|------|----------|------------------|
| 1   | 講師ID      | F_InstractorID   | CHAR        | 4    | PK   | NOT NULL | ゼロ埋め4桁（例：0011）|
| 2   | 名前        | F_Name           | VARCHAR     | 50   |      | NOT NULL | 必須             |
| 3   | 電話番号    | F_PhoneNo        | VARCHAR     | 20   |      |          | ハイフン含む形式  |

| 0202           | 小林 典子 | NULL           |

## データ型の選定理由

| 項目          | データ型    | 理由                                         |
|---------------|-------------|----------------------------------------------|
| コースコード  | CHAR(4)     | 常に英字2字＋数字2桁の固定4文字              |
| コース名称    | VARCHAR(100)| 長さが変わるテキスト                         |
| 料金          | INT         | 整数の金額（小数点なし）                     |
| 開催期間      | INT         | 日数（整数）                                 |
| 講師ID        | CHAR(4)     | ゼロ埋め固定4文字（0011 など）               |
| 名前          | VARCHAR(50) | 長さが変わる氏名                             |
| 電話番号      | VARCHAR(20) | ハイフン付き文字列（080-0001-0001 など）     |
