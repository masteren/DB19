## 参照制約
### ① insert into T_Sales values(4,'999','2020/05/31');
エラーになります（挿入失敗）。
子表に入れようとした F_GID='999' が、親表 T_Goods に存在しないためです。「親キーが見つからない」状態にあたります。
・MySQL：ERROR 1452 (23000): Cannot add or update a child row: a foreign key constraint fails
・Oracle：ORA-02291: integrity constraint violated - parent key not found
### ② delete from T_Goods where F_GID='100';
エラーになります（削除失敗）。
削除しようとした親行 100 が、子表 T_Sales から参照されている（F_SID=2 の行）ためです。親行を消すと子行の外部キーが宙に浮くため拒否されます。
・MySQL：ERROR 1451 (23000): Cannot delete or update a parent row: a foreign key constraint fails
・Oracle：ORA-02292: integrity constraint violated - child record found
### ③ update T_Goods set F_Gid='555' where F_Gid='100';
エラーになります（更新失敗）。
親キー 100 を 555 に変えると、100 を参照していた子行が対応する親キーを失うため、削除と同じく参照整合性を壊します。
・MySQL：②と同じ ERROR 1451（メッセージ自体が "delete or update a parent row" となっており、親行の削除と更新を同じ番号でまとめています）
・Oracle：ORA-02292（child record found）
### ④ delete from T_Goods where F_Gid='100';
②とまったく同じで、エラーになります。
理由も同じで、100 が子表から参照されているため削除できません（MySQL：1451、Oracle：ORA-02292）。
