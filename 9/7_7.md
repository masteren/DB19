# Index
## データベースインデックス（索引)

### テーブルの検索を高速化するための仕組み。

## 内部構造
        多くのDBMSでは B木（B-tree / B+木） を使う。

        データが常にソートされた状態で保持される
        探索・挿入・削除が O(log n) でできる
        範囲検索（BETWEEN、>、<）にも強い

        一部では ハッシュインデックス も使われるが、これは等価検索（=）専用で範囲検索には使えない。
## 作成の構文

###  基本
        CREATE INDEX idx_users_email ON users (email);

        -- ユニークインデックス（重複を許さない）
        CREATE UNIQUE INDEX idx_users_email ON users (email);

        -- 複合インデックス（複数列）
        CREATE INDEX idx_orders_user_date ON orders (user_id, created_at);

        SELECT * FROM users WHERE email = 'masteren@example.com';

        EXPLAIN SELECT * FROM users WHERE email = 'masteren@example.com';
