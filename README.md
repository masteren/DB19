# DB19 - Database Study Notes

## 中文

这是每周二数据库课程学习内容的 GitHub 上传用仓库。

### 2026-04-28

本周主题是 DB2 SQL 复习。老师发了课题 1 的模板文件，本仓库只记录本节课复习到的 SQL 写法和作业用空白框架，不直接填写作业答案。

### 学习内容
- `SELECT` / `FROM` 的基本查询结构
- `WHERE` 条件筛选
- `COUNT`、`MAX` 等聚合函数
- `GROUP BY` 和 `HAVING`
- 表连接：旧式 `WHERE` 连接和 `JOIN ... ON`
- `LEFT JOIN` 与 `IS NULL`
- SQL 注释：`--` 单行注释、`/* */` 多行注释
- MySQL 终端登录和基础操作命令

### 文件说明

之后每周二根据课堂内容继续更新。
